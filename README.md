# PP-FF-SHOP

A responsive, static storefront concept for Free Fire top-ups and memberships. Built with plain HTML, CSS, and JavaScript so it can be hosted as a static site.

## Run locally

Open `index.html` in a browser, or serve this directory with any static file server. No build step is required.

## Before launch

This repository currently contains a front-end demo only. Product names and prices are sample content. The cart and checkout are client-side demonstrations and do not create orders, collect payment, or fulfill top-ups. Before accepting real orders, verify current product availability and regional pricing, add a secure order backend and payment provider, and review applicable game publisher and consumer-protection requirements. PP-FF-SHOP is not affiliated with or endorsed by Garena or Free Fire.

## Files

- `index.html` — storefront structure and content
- `styles.css` — responsive visual design
- `app.js` — sample product catalog, cart, and demo checkout interactions
